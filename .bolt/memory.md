# Project memory

## Product intent & audience

- "Mini Cookies" creator program/platform with a marketing landing/home page.
- Audience: prospective creators; page drives them toward an "APPLY NOW" action.
- Home page sections include an earnings calculator and a testimonials section.
- Application form section serves as the final conversion point on the home page.

## Brand personality & voice

- Action-oriented, creator-focused, encouraging tone.
- Section CTAs use uppercase imperatives (e.g., "APPLY NOW").
- Conversational, low-pressure messaging for the application section ("chill conversation," "no commitments yet").

## Visual design & UX direction

- Section headlines: large bold italic style with selected words highlighted in pink; consistent across all home sections.
- Each section uses a numbered divider bar at the top as a shared structural motif.
- Color palette: pink as the primary accent (headline highlights, primary buttons, pill labels); outlined button style for secondary actions; subtle dark borders for media frames.
- Buttons: pink filled primary buttons, outlined secondary buttons, pill-shaped labels for tags/categories.
- Testimonials section: 2-per-row grid of 4 vertical 9:16 video placeholder boxes; each box followed by a pink pill label and outlined "Case Study" button; centered "APPLY NOW" button at bottom.
- Application form section: headline ("One Message Can Change Everything") and subheadline above the form fields, replacing a former standalone CTA section.
- Layout/spacing consistent with existing home sections (same structure, font family, headline sizing).

## Decisions, constraints & rationale

- Standalone "One Message Can Change Everything" CTA section was deleted; its copy relocated to serve as headline/subheadline for the application form section.
- Testimonial video boxes are intentionally empty placeholders awaiting future video assets — do not add video elements/players yet.
- Styling intentionally matches existing sections (headline color/size/structure, divider bar, button styles) to keep visual consistency.

## Open questions & assumptions

- Video sources/URLs and case study links/targets for each testimonial are not yet defined.
- "APPLY NOW" button target/behavior not yet specified.
- Exact testimonial copy beyond numbered placeholders is pending.
- Assumes existing headline/divider/button styles are available as reusable patterns or can be mirrored from current sections.
